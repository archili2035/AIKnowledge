### Hermes Agent（2026 年 2 月发布，4 月爆火）

> **两个月 GitHub 4.7 万星，连续两周霸榜 Trending Top 5 的开源自进化 AI Agent 框架。**

| 项目 | 详情 |
|------|------|
| 开发商 | Nous Research |
| 发布时间 | 2026 年 2 月 |
| 许可证 | **MIT**（完全开源） |
| 官网 | [hermes-agent.org](https://hermes-agent.org) |
| GitHub Stars | **~47,000+**（截至 4 月中旬），单日峰值新增 6400+ |

#### 核心定位

不是聊天机器人、不是 IDE 代码补全工具——是一个**住在服务器上的持久个人智能体**，运行越久越了解用户，能力越强。

#### 核心差异化：自进化闭环

| 能力层 | 说明 |
|--------|------|
| **持久记忆系统** | 跨会话记住偏好、项目和环境；数据本地存储在 `~/.hermes/`，零云端锁定 |
| **自动技能创建** | 解决难题时自动生成可复用 **Skill（SKILL.md）**；下次遇到类似问题直接调用旧经验，并在使用中不断修正优化 |
| **MLOps 自训练雏形** | 运行过程中产生大量工具调用轨迹，集成 Atropos RL 训练框架，支持导出 ShareGPT 格式用于模型微调 |

#### 架构与能力

- **多平台消息网关**：Telegram / Discord / Slack / WhatsApp / Signal + CLI 终端
- **多执行环境**：本地终端、Docker（安全加固）、SSH 远程、Modal / Singularity 云端/HPC
- **并行子智能体**：为并行工作流生成隔离子智能体，各有独立对话和终端
- **浏览器自动化**：网页搜索、页面提取、导航点击、视觉分析、TTS、多模型协作推理
- **定时任务调度**：内置 cron 调度器，支持无人值守的每日报告、备份、审计等
- **模型无关架构**：Nous Portal 原生接入 / OpenRouter（200+ 模型）/ 自定义 OpenAI 兼容端点 / 本地 vLLM

#### 与 OpenClaw 对比

| 维度 | Hermes Agent | OpenClaw |
|------|--------------|----------|
| 核心理念 | **自进化**（Evolutionary）：经验涌现，自动沉淀 Skill | **确定性**（Deterministic）：人工预设能力和边界 |
| 记忆机制 | 分层认知记忆：不仅检索信息，更建立"关于你的模型" | 显式记忆/RAG：知道信息在哪里并调取 |
| 适用场景 | 探索性/创意开发：流程模糊、需试错的任务 | 高稳定性任务：批量处理、金融交易等容错率低场景 |
| 角色定位 | "动脑"：规划器、高级推理、技能生成 | "干活"：执行器、多通道交互、生态对接 |

社区共识：两者互补而非替代，常见用法是将 Hermes 作为高级规划器运行在 OpenClaw 工具之上。

#### 注意事项

- 开发团队 Nous Research 成员多来自 Web3/加密货币领域，融资约 7000 万美元来自加密机构
- 目前仍处于实验阶段，距离普通用户"开箱即用"还有距离
- 加密社区已出现关于"空投代币"的非官方炒作，需注意甄别

## 三、关键趋势

### ① 开源追平闭源
GLM-5.1 在 SWE-Bench Pro 击败 GPT-5.4；Gemma 4（31B）打平 Llama 4（400B）。"开源落后闭源 6 个月"的叙事已经失效。

### ② 安全门控成为新策略
Claude Mythos 因安全原因被扣留——**首次有主流实验室公开声明"造出了过于强大而无法广泛发布的东西"**。未来所有前沿模型都将面临"是否过于强大"的问题。

### ③ 多模态成为默认配置
本月所有主要发布均支持图像/音频/视频。纯文本 LLM 产品类别基本终结。

### ④ Agent 时代到来
Qwen 3.6-Plus、GLM-5V-Turbo 均面向自主 Agent 工作流设计。模型从"回答问题"进化为"执行任务"。**Hermes Agent** 以"自进化"范式爆火（两个月 4.7 万星），代表 Agent 从"一次性工具"向"可持续进化的资产"转变。

### ⑤ 小模型大飞跃
Gemma 4（31B）在多项基准超越数百亿参数的大模型；Bonsai 8B（1-bit 量化）让边缘/设备端推理成为现实。

### ⑥ 超长上下文标配化
Llama 4 Scout 达 1000 万 token；主流前沿模型普遍 100 万+。

### ⑦ 开源策略分化
Meta 首次推出闭源模型（Muse Spark）；Google 保持 Apache 2.0 全开放；智谱采用 MIT 最宽松许可。

### ⑧ 国产算力生态突围
DeepSeek V4 原生适配华为昇腾 950PR，标志国产 GPU 在大模型训练与推理领域建立自主生态。
